# Shell (console-wide)

Types: `src/features/shell/api.ts` · Mock: `src/features/shell/mock.ts`

| Endpoint                       | Permission     | Response                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------ | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /status`                  | signed in      | `{ data: { operational: bool, incident: { title, posted_at } \| null } }` — header status pill (polled every 60 s).                                                                                                                                                                                                                                                                                                                                                                                        |
| `GET /badges`                  | `support.view` | `{ data: { support: int } }` — open ticket count for the sidebar (polled every 60 s; not requested without the permission).                                                                                                                                                                                                                                                                                                                                                                                |
| `GET /notifications`           | signed in      | `?before={cursor}` · `{ data: [{ id, text, tone: good\|warn\|bad, created_at, read, href }], meta: { has_more, next_cursor } }` newest first, 30 a page. The bell reads the first page; "Load older" passes `meta.next_cursor` back as `before` (opaque: base64url of `{created_at unix seconds}.{id}` of the page's last row; blank = newest page; malformed or >120 chars → 422 `before`).                                                                                                               |
| `POST /notifications/read-all` | signed in      | `204`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `GET /search?q=&type=`         | signed in      | `{ data: [{ type: tenant\|invoice\|ticket\|staff, id, label, sublabel, href }] }` max 20. `q` required, 2–100 characters (422 otherwise; the palette waits for 2). Only include types the user may view (`tenants.view`, `billing.view`, `support.view`, `staff.view`). Invoices: `label` = number, `sublabel` = `{tenant} · {amount}`; tickets match subject, tenant name or `#number` (`label` = subject, `sublabel` = `#{number} · {tenant}`, `href` `/support?ticket={id}`). `href` is a console path. |
